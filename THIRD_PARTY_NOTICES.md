# Third-party components

This project's detector adapters use separately licensed dependencies and model assets. No claim is made that the complete stack has one permissive license.

- **MediaPipe 0.10.35 (legacy only):** Historical adapters and tests retain the [official MediaPipe SDK](https://github.com/google-ai-edge/mediapipe), Apache 2.0. The active hybrid backend no longer loads MediaPipe or interprets its joints. See [legacy MediaPipe notes](docs/MEDIAPIPE.md).

- **Three.js 0.186.0:** The Bus Studio uses the [official Three.js renderer and addon sources](https://github.com/mrdoob/three), distributed under the MIT license. The full license is included as `static/bus/LICENSE.three.txt`; the minified bundle also retains its upstream notice. The bus, stop, seats and passenger geometry are created by this project's code.
- **esbuild 0.28.2:** [Official build tool](https://github.com/evanw/esbuild), MIT licensed. Used locally to produce the prebuilt bus JavaScript bundle; not required to run it.

- **Ultralytics / YOLOE:** [official source and AGPL-3.0 license](https://github.com/ultralytics/ultralytics/blob/main/LICENSE), [YOLOE documentation](https://docs.ultralytics.com/models/yoloe/). Installed release: 8.4.143. The default model and text-encoder assets come from [Ultralytics assets, release v8.4.0](https://github.com/ultralytics/assets/releases/tag/v8.4.0).
- **CLIP tokenizer:** [Ultralytics CLIP repository](https://github.com/ultralytics/CLIP), pinned to commit `a13192f8cb767260d7dfd98c843b0716593169e7`. Retain the upstream package's license when redistributing it.
- **Sample photograph:** `static/sample.jpg` is copied without modification from `ultralytics/assets/bus.jpg` in the installed Ultralytics package. It is an upstream test/demo asset, not an image created for this project. See the [original file](https://github.com/ultralytics/ultralytics/blob/main/ultralytics/assets/bus.jpg) and the Ultralytics license linked above.
- **Grounding DINO Tiny:** The default hybrid backend uses the [official model and Apache-2.0 declaration](https://huggingface.co/IDEA-Research/grounding-dino-tiny) at revision `a2bb814dd30d776dcf7e30523b00659f4f141c71` for detailed phrases. [Official source](https://github.com/IDEA-Research/GroundingDINO). `scripts/setup_grounding.py` downloads its configuration, tokenizer and SHA-256-verified safetensors weights separately; weights are excluded from the source archive. Inference uses Hugging Face Transformers 4.57.1 with remote model code disabled.
- **LocateAnything-3B (historical optional adapter):** [NVIDIA model card](https://huggingface.co/nvidia/LocateAnything-3B), [research/evaluation license](https://huggingface.co/nvidia/LocateAnything-3B/blob/main/LICENSE). The historical local worker pins revision `c32291ca5e996f5a7a485845b4f57a233936bba0`. No weights are bundled with this project. [Runtime setup and limits](docs/INSIDE_POSTURE.md).
- **FFmpeg:** The export fallback executable is supplied by [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg). FFmpeg's own build configuration and licenses apply to that binary.
- **Tracking:** BoT-SORT, its Kalman filter and sparse-optical-flow camera compensation are used through the pinned Ultralytics package. See the [BoT-SORT authors' repository](https://github.com/NirAharon/BoT-SORT) and [Ultralytics tracker implementation](https://github.com/ultralytics/ultralytics/blob/main/ultralytics/trackers/bot_sort.py). LAP 0.5.12 provides assignment; its installed package retains its license.
- **Adaptive filtering:** The local filter implements the [One Euro algorithm by Casiez, Roussel and Vogel](https://gery.casiez.net/1euro/), using real timestamps and separate center/size cutoff settings.

The installed Ultralytics license is included as `LICENSE.ultralytics.txt`. Other Python package metadata and licenses are retained in the installed environment. `requirements-lock-windows.txt` records the exact installed versions. The source archive excludes the environment, downloaded model weights and user data.
